# AppointmentBooking

A multi-tenant appointment booking SaaS platform built with **Next.js**, **Supabase**, **AWS RDS**, and AI agent integration.

## Structure
- `appointmentbooking`: Core booking platform (frontend + backend).
- `appointmentbookings.agent`: AI agent for automation, reminders, and analytics.

## Deployment
- Main platform: [appointmentbooking.co.za](https://appointmentbooking.co.za)
- Tenant example: [instylehairboutique.co.za](https://instylehairboutique.co.za)

## Features
- Multi-tenant booking system
- AI-powered appointment management
- Supabase + RDS integration
